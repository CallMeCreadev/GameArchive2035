This folder contains descriptions of SQL injection, an introductory hacking technique that exploits vulnerabilities in improperly sanitized database queries.

Most modern developers mitigate this risk by parameterizing queries, but some older or poorly maintained websites may still be vulnerable.

How It Works

Consider the following SQL query:
string query = "SELECT * FROM Users WHERE Username = '" + userInput + "'";

At first glance, this seems like a simple way to retrieve user information based on input. You might expect users to enter a legitimate username, and the query will execute as intended.

However, this approach has a critical flaw—it allows malicious users to manipulate the query structure.

For example, if an attacker enters:

' OR '1'='1

The query dynamically constructs:

SELECT * FROM Users WHERE Username = '' OR '1'='1'

Since '1'='1' is always true, the database returns all users, effectively bypassing authentication.

In other words, this exploit turns the database into an obedient servant—doing whatever the attacker wants
