The Role of System Administrators

In our organization, system administrators are the custodians of security and functionality. 


Access Codes

System administrators are granted automatic access to our first layer of security which guards the secure file system. 
Future Levels in our system require proper access codes.
Due to poor security some of our systems may be vulnerable, some codes may even be left lying around in plain text files.

Operations

Any access to this website will return the user to the startup page.
It may be useful to write down access codes to streamline access, Just be sure to store them in a safe place.
